# Command Palette Ideas

A list of potential features, links, and minigames to be added to the command palette.

## Minigames
- **Minesweeper**: A classic grid-based logic puzzle.
- **2048**: A sliding tile puzzle game.
- **Tetris**: A block-falling puzzle game.
- **Hangman**: A word-guessing game.
- **Memory Match**: A card-flipping memory game.
- **Sudoku**: A number-placement puzzle.
- **Space Invaders**: A simple retro shooter.
- **Flappy Bird Clone**: A simple one-button navigation game.
- **Platformer Mini-Level**: A tiny screen-sized platforming challenge.

## Useful Tools & Utilities
- **Unit Converter**: Length, weight, temperature, etc.
- **Currency Converter**: Real-time (or cached) currency exchange rates.
- **Password Generator**: Customizable length and complexity.
- **Color Picker**: A visual tool to generate hex/rgb codes.
- **JSON Formatter**: A quick way to beautify minified JSON.
- **Base64 Encoder/Decoder**: For developer convenience.
- **Stopwatch / Timer**: Quick time tracking.
- **Pomodoro Timer**: A productivity tool with preset intervals.
- **Markdown Live Preview**: Small pane to test markdown snippets.
- **Weather Widget**: Showing current weather for a set location.
- **System Info**: Browser version, OS, screen resolution.

## Navigation & Social Links
- **Social Media Profiles**: LinkedIn, Twitter/X, Mastodon, Discord server.
- **Project Repositories**: Direct links to major open-source contributions.
- **Resume/CV**: A direct link to a PDF or web version.
- **Contact Form**: A quick shortcut to the contact section.
- **Latest Blog Post**: A dynamic link to the most recent update.
- **Support / Buy Me a Coffee**: Links for donations or support.

## Dynamic Content
- **Today's Quote**: A randomized inspirational or tech-related quote.
- **GitHub Activity Feed**: A summary of recent commits or stars.
- **RSS Feed Reader**: A small pane showing headlines from favorite sites.
- **Daily Goal Tracker**: A simple checklist that resets daily.
- **Random Wikipedia Article**: For quick learning.
